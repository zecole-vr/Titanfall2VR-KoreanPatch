# Titanfall 2 VR 한글패치

타이탄폴 2 VR 모드(PCVR)의 비공식 한글패치입니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 최신 버전 | **v0.2.29** |
| 지원 게임 | 타이탄폴 2 PCVR (Windows, Steam/EA) + VR 모드 **1.0.25** 기준 |
| 설치 도구 | [ZECOLE VR 런처](https://github.com/zecole-vr/zecole-launcher) (Windows 10/11 64비트, WebView2, .NET Framework 4.8) |
| 사용 폰트 | IBM Plex Sans KR (SIL OFL 1.1) |
| 제작 | 유튜브 크리에이터 제콜 (ZECOLE) · [YouTube](https://www.youtube.com/@zecole) |

> **튜토리얼 외의 구간은 아직 검수하지 않은 버전입니다.**

## 설치

**[ZECOLE_Launcher.exe 받기](https://github.com/zecole-vr/zecole-launcher/releases/latest/download/ZECOLE_Launcher.exe)** · 설치 없이 바로 실행 · 설치·업데이트·원본 복구를 모두 런처에서 합니다.

**타이탄폴 2 설치 → VR 모드 설치 → 한글패치 설치** 순서로 진행해 주세요.

1. 타이탄폴 2를 설치합니다.
2. [VR 모드 설치기](https://github.com/CircuitLord/CircuitLordVRModInstaller/releases/latest)로 타이탄폴 2 VR 모드를 설치합니다.
3. 게임을 종료하고 런처를 실행한 뒤 왼쪽 목록에서 **Titanfall 2 VR**을 고릅니다.
4. **한글패치 설치**를 누릅니다. Windows 관리자 권한 요청이 나오면 허용해 주세요.
5. 설치가 끝나면 런처의 **VR 게임 실행**으로 게임을 시작합니다.
6. 게임의 **설정 → 사운드**에서 **자막을 켜 주세요.** 자막을 켜야 대사 자막이 표시됩니다.

- VR 모드가 업데이트되면 한글 파일 일부가 바뀔 수 있습니다. 런처의 **설치 확인 / 재설치**로 다시 맞춘 뒤 **VR 게임 실행**을 눌러 주세요.
- VR 모드 자체의 업데이트는 공식 VR 모드 설치기에서 진행합니다.
- 새 한글패치 버전이 나오면 런처가 **업데이트 있음**으로 알려 주며, 같은 화면에서 설치하면 됩니다.

## 제거 방법

게임을 종료한 뒤 런처의 Titanfall 2 VR 화면에서 **원본 복구**를 누르세요.

## 패치노트 (v0.2.29)

- VR 모드 1.0.25를 기준으로 미번역·변경된 문구 166개와 관련 안내 스크립트를 수정했습니다.
- VR 해상도, 계단 현상 완화, 반짝임 감소, 타이탄 머리 방향 회전 설정과 도움말을 번역했습니다.
- 사첼 폭탄 기폭, 타이탄 능력 방향 및 사망 시 조언을 최신 조작법에 맞췄습니다.
- 후반부 타이탄 시스템 메시지, 프로토콜, 홀로그램 상태창 등 누락된 번역을 보완했습니다.
- 짚라인 호출 패턴과 첫 캘리브레이션 안내 이미지의 파일 호환성을 확인했습니다.

### 확인 범위

- 별도 시험 폴더에서 설치·업데이트·재설치·복원과 손상된 패키지 거부를 확인했습니다.
- 실제 게임 폴더 설치와 헤드셋 플레이 검증은 진행하지 않았습니다.
